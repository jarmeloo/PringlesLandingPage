## 🚀 About the project

A landing page built for the **Pringles** brand, recreating the brand's visual identity and playful tone through a modern interface, interactive flavor sections, and smooth navigation.

The project simulates an official Pringles promotional page, showcasing the brand's main flavors and reinforcing the classic concept *"Once You Pop, You Can't Stop"*.

- Flavor showcase in a carousel format
- Interface inspired by the brand's visual identity
- Responsive layout
- Highlight sections with product categories
- Modern landing page structure
- Simple, straightforward navigation

## 🧩 Technologies used

* **HTML**
* **CSS**
* **JavaScript**

## 🎨 Features

* 🥔 Flavor carousel (Salt & Vinegar, Ham & Cheese, Paprika, Cheese & Onion)
* 🎯 Interactive buttons (SEE MORE)
* 🔥 "Once You Pop, You Can't Stop" section with category cards (Flavor, Blast, Iconic)
* 🧭 Header with navigation (Home, Promotions, Our Products, Contact)
* 🖼️ SVG/WEBP icons and illustrations to reinforce brand identity

## 📱 Responsiveness

The layout was built to adapt to different screen sizes, ensuring a smooth experience on both mobile and desktop.
